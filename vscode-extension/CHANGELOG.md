# Changelog

All notable changes to the "schemagraph" extension will be documented in this file.

## [1.0.0] - Initial Release
- Multi-framework automatic schema discovery (Laravel, Django, Rails, Go GORM, Spring JPA, Prisma, Mongoose, Sequelize, TypeORM, GraphQL, SQL).
- Live split-tab interactive ERD Webview panel with drag & drop cards, cubic bezier connection lines, and minimap radar.
- Automatic hot-reloading on schema file save.
- 1-Click export to SVG, HTML, DBML, SQL DDL, Mermaid Markdown, and AI context prompts.
- Editor title bar and status bar shortcuts.
- Support for VS Code, Cursor, Windsurf, and Antigravity IDE.
